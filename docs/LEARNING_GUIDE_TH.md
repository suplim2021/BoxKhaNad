# คู่มือเข้าใจโค้ด BoxKhaNad แบบสั้น

เป้าหมายไม่ใช่จำโค้ดทุกบรรทัด แต่ให้อธิบายได้ว่าแต่ละส่วนทำหน้าที่อะไรและตรวจว่าผลสมเหตุสมผลหรือไม่

## 1. สูตรหลัก

ไฟล์: `app/lib/box-fit.ts`

ถ้าของยาว 10 ซม. และห่อกันกระแทกหนา 1 ซม. ต่อด้าน:

`ความยาวหลังห่อ = 10 + (1 x 2) = 12 ซม.`

ทำแบบเดียวกันกับกว้างและสูง ฟังก์ชัน `calculatePackedSize` ทำงานนี้

## 2. ทำไมต้องลองหมุน

ของขนาด `10 x 20 x 5` อาจใส่กล่อง `20 x 10 x 5` ได้เมื่อหมุน ฟังก์ชัน `getRotations` สร้างท่าที่เป็นไปได้สูงสุด 6 ท่า และตัดท่าซ้ำออก

## 3. เลือกกล่องอย่างไร

ฟังก์ชัน `findBoxes` ทำ 4 ขั้น:

1. คำนวณขนาดหลังห่อ
2. ลองทุกท่ากับแต่ละกล่อง
3. เก็บกล่องที่มีขนาดพอ
4. เรียงจากพื้นที่เหลือน้อยที่สุด

กล่องแรกคือคำแนะนำ กล่องถัดไปคือทางเลือกใหญ่ขึ้น และกล่องที่ขาดพื้นที่น้อยที่สุดคือภาพ “เล็กไป”

## 4. ทำไมเว็บเขียนว่า “น่าจะเหมาะ”

ไฟล์: `app/data/boxes.ts`

แหล่งข้อมูลส่วนใหญ่บอกเพียง “ขนาด” แต่ไม่ยืนยันว่าเป็นพื้นที่ด้านใน ดังนั้นระบบใช้ข้อมูลเหล่านี้เพื่อเทียบเบื้องต้น แต่ไม่รับรองว่าใส่ได้แน่นอน นี่เป็นการตัดสินใจด้านความซื่อสัตย์ของผลิตภัณฑ์ ไม่ใช่ข้อผิดพลาดของสูตร

## 5. หน้าจอทำงานอย่างไร

ไฟล์: `app/components/BoxCalculator.tsx`

- `useState` จำค่าที่ผู้ใช้เลือก
- เมื่อค่าหนึ่งเปลี่ยน `findBoxes` จะคำนวณใหม่ทันที
- `BoxComparison` รับเฉพาะขนาดและชื่อกล่อง แล้ววาดภาพด้วย HTML/CSS
- ไม่มีการส่งข้อมูลผู้ใช้ไป API หรือฐานข้อมูล

## 6. Tests คืออะไร

ไฟล์: `tests/box-fit.test.ts`

แต่ละ test เป็นตัวอย่างคำถาม เช่น “ห่อ 1 ซม. ต้องเพิ่ม 2 ซม. จริงไหม” หรือ “ของหมุนแล้วใส่ได้ไหม” ถ้าแก้โค้ดจนคำตอบผิด test จะล้มและบอกตำแหน่งให้ตรวจ

## ประโยคที่ใช้อธิบายในวิดีโอได้

“ผมกำหนดกฎการคำนวณจากปัญหาที่เจอจริง: วัสดุกันกระแทกต้องเพิ่มสองด้านและของสามารถหมุนได้หลายท่า Codex ช่วยเขียนและทดสอบกฎเหล่านี้ ส่วนผมตัดสินใจให้ผลลัพธ์ใช้คำว่า ‘น่าจะเหมาะ’ เพราะแหล่งข้อมูลกล่องไม่ยืนยันขนาดภายใน”

ก่อนส่งจริง ให้ลองเปลี่ยนตัวเลขในเว็บ 2-3 ชุดและอ่าน test แต่ละข้อ หากผลไหนไม่เข้าใจให้ถามจากชื่อ test ได้โดยตรง
